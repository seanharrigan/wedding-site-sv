# Blank Stationery Image Library

Thirty standalone transparent PNG assets inspired by the supplied Mexican-chic, old-world wedding stationery references. Every image contains one blank object only, with no text, names, typography, photographs, people, logos, watermark, table, fabric, or mockup background.

## Palette

- Warm ivory and cream
- Rich mocha and espresso brown
- Muted olive, sage, and agave green
- Restrained accents of clay, dusty rose, parchment tan, and muted terracotta

# Generation Direction

Use case: product-mockup

Asset type: independent high-resolution wedding stationery PNG for flexible layering in Canva and website compositions.

Reference images: use the supplied portrait and landscape invitation-suite images only as visual references for material, palette, edge treatment, embossing, Mexican-inspired cut-paper details, restraint, and old-world luxury mood. Do not reproduce their full compositions.

Shared style: sophisticated Mexican-chic wedding stationery; tactile handmade cotton paper; warm natural studio light; restrained embossed or debossed contour details; realistic paper thickness; refined craftsmanship; clean antialiased cutout edges.

Shared palette: warm ivory, cream, espresso and rich mocha brown, muted olive, sage and agave green, with occasional restrained clay, dusty rose, parchment tan, or muted terracotta.

Critical constraints: create exactly one complete object per image; fully transparent background and comfortable transparent padding; object straight-on and completely visible; blank usable surface; no text, names, letters, numbers, monograms, logos, typography, photographs, people, illustrations, watermarks, hands, table, fabric, neighbouring stationery, mockup scene, artificial frame, or unrelated cast shadows. Preserve only the object's own soft contact shadow. For lace pieces, every cutout must be genuinely transparent.

Each numbered filename in `README.md` is generated as a distinct asset using this shared direction plus its individual description.
